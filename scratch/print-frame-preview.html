A4 fits most of this circuit - the source and part of the cylinder fall outside the sheet. Nothing about the diagram itself changes; it's a print guide, not a boundary.

Why a dropdown, not a toggle

None keeps today's behavior exactly as-is. A4/A3 match the sizes people actually print or drop into a PDF report, without inventing a whole paper-size picker for a niche need.

Purely visual

The frame never clips content, blocks clicks, or affects the grid/snap. It's drawn once, below the components, the same way the grid lines already are.

Pairs naturally with Export

A likely next step: "Export → as PNG" could offer "fit to frame," cropping the image to exactly the sheet instead of the current auto-bounds around everything drawn.
